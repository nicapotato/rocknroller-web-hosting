Rock N Roller

Play Versions

A freeware guitar-practice app that plays Rocksmith-format .psarc charts — built around freeware CDLC from the CustomsForge community. Runs entirely in your browser (Chromium recommended); a demo song is preloaded, and you can grant a local folder of your own CDLC.

▶ Play latest

What it does

Point it at a folder of CDLC .psarc files and it renders the charts on a 3D highway with audio, practice speed control (pitch-preserving time stretch), per-arrangement tuning info, playlists and profiles. The web version ships with one demo song — Deadwing by Porcupine Tree, a freeware community chart — so there is something to play before you add your own library.

Your files stay yours

In the browser, the app asks for read access to a local folder using the browser folder picker. Files are read locally in the page; nothing is uploaded. Saved state (profiles, playlists, scan cache) lives in your browser's local storage for this site.

What it is not

This project is not affiliated with Ubisoft or Rocksmith, and it does not host, distribute, or bypass official Rocksmith DLC. It reads chart files you already have. Support official releases and the artists who make the music.

Platforms

Play in the browser at /latest (Chromium recommended), or grab desktop builds for macOS (Apple Silicon and Intel) and Windows from the versions page or itch.io.

Your song files never leave your machine — the web app reads granted folders locally in the browser.

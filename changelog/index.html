0.2.0 — One library folder

Version 0.2.0 stores one library folder instead of a list of PSARC roots plus a separate stems picker. Choose that folder once, then Batch sync to scan it. The app never copies your charts.

If you own Rocksmith 2014

Point Settings at the game’s install folder — the same directory Steam names Rocksmith2014. The in-app LIBRARY FOLDER hint prints the expected Steam path for this OS (table below). On desktop, Choose library folder opens in Rocksmith2014 itself when the game is installed — the game root, not its dlc/ subfolder — or in steamapps/common otherwise (suggestion only; nothing is bound until you pick). Open folder reveals that install in Finder, Explorer, or the Linux file manager so you can drop custom .psarc files into dlc/.

Desktop only. The web player cannot open these Steam folders: Chrome blocks Program Files, AppData and ~/Library. In the browser, copy songs.psarc + dlc/ (+ stems/) to an ordinary folder and choose that — see Web player folders.

Platform Expected Steam folder
macOS ~/Library/Application Support/Steam/steamapps/common/Rocksmith2014
Windows C:\Program Files (x86)\Steam\steamapps\common\Rocksmith2014 (or %ProgramFiles%\Steam\steamapps\common\Rocksmith2014 if Steam is not in (x86))
Linux ~/.steam/steam/steamapps/common/Rocksmith2014 (or ~/.local/share/Steam/steamapps/common/Rocksmith2014)

Official DLC already lives in that dlc/ tree. Custom charts can sit beside it, or in a subfolder such as dlc/cdlc/. Stem mixes go in stems/ next to the game (see below).

If you do not own the game

Create any folder with the same two subdirectories. The app creates dlc/ and stems/ if they are missing: 

MyLibrary/
  dlc/          # your *_p.psarc / *_m.psarc (subfolders are scanned)
  stems/        # optional Demucs mixes, one folder per chart

Then choose MyLibrary — not dlc/ itself — and run Batch sync.

dlc/ is recursive

Every playable *_p.psarc (PC) and *_m.psarc (Mac) under dlc/ is catalogued, including nested folders. Organize however you like: 

dlc/
  some_song_p.psarc
  cdlc/
    another_song_m.psarc
    artist/
      third_song_p.psarc

Hidden folders (names starting with .) are skipped. Root game archives that sit next to dlc/ are not catalogued — only files under dlc/ count. After you add or move charts, run Batch sync again.

stems/ — six MP3s per chart

Stem mixes live under the same library folder, not a second picker. Rock N Roller looks up the chart filename without .psarc, then requires all six MP3s: 

{library}/stems/{psarc_basename}/
  drums.mp3
  bass.mp3
  other.mp3
  vocals.mp3
  guitar.mp3
  piano.mp3

Example: dlc/cdlc/Eagles_Hotel-California_v1_1_p.psarc matches stems/Eagles_Hotel-California_v1_1_p/. The folder name must match the archive basename exactly. A PC file (Foo_p.psarc) and a Mac file (Foo_m.psarc) keep separate stem folders.

Separation still runs offline in Demucs MLX. Point its output at {library}/stems, or copy the six files into the right basename folder, then Batch sync. Full mixer notes: stems & Demucs.

Web player folders

Chrome’s File System Access API refuses system and app-data folders — on Windows C:\Windows, C:\Program Files, C:\Program Files (x86) and AppData; on macOS ~/Library and the system folders; on Linux /dev, /sys and /proc. Steam installs Rocksmith 2014 inside one of them, so the web player needs a copy of the game files somewhere ordinary, such as Documents/RockNRoller: 

Documents/RockNRoller/
  songs.psarc   # needed for Rocksmith 1 import packs
  dlc/          # copied from …/Rocksmith2014/dlc
  stems/        # optional

Picking a blocked folder now shows an explanation in the player instead of failing silently. Settings and the empty library screen carry the same note on the web build.

Sync and loading feedback

  • Batch sync opens a progress window: spinning cog, “Song X of N”, the current phase (looking for songs, checking, parsing, removing missing, loading catalog), the file being read, and new / updated / unchanged / removed counts. Hide keeps the scan running in the background; Cancel stops it.
  • The song loading overlay names each step: opening the PSARC, reading arrangements, parsing each chart (“PARSING CHARTS 2/4 — Lead chart”), extracting and decoding audio, and loading stems.
  • Fixed: with autoplay on, the next song could stay on “loading” forever when its audio needed a background decode.

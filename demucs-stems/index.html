Stems & Demucs

Stem mode lets you mix six isolated tracks — drums, bass, other, vocals, guitar, piano — each with its own fader (0–200%). Mute the guitar and play over the rest of the band, or solo a part to learn by ear. Combined with pitch-preserving speed and section loops, this is the usual “drill this four bars” workflow.

The desktop stems builds separate songs themselves. Right-click a song in the library, choose Add to stems queue, and Rock N Roller runs Demucs in the background while you keep playing. Every desktop platform has a stems build: macOS (Apple Silicon and Intel), Windows and Linux.

The standard desktop builds and the web player cannot separate, but they play any stems you already have. To make stems without the stems build, use the standalone Demucs App.

Built-in separation

The stems builds bundle Meta's Demucs htdemucs_6s model (the six stems above) and a native worker for each platform. Each song runs in its own worker process, so a crash or a cancel never takes the player down with it. The audio comes straight out of the .psarc; you do not export anything first.

Stems build Separator Runs on Download
macOS Apple Silicon mlx-c GPU (Metal) ~126 MB
macOS Intel (10.15+) ONNX Runtime CPU ~172 MB
Windows x64 ONNX Runtime GPU through DirectML (NVIDIA, AMD or Intel), or CPU ~185 MB
Linux x86_64 ONNX Runtime CPU ~193 MB

Apple Silicon keeps the MLX worker because it is faster there than ONNX. The standard (non-stems) builds are about 4 MB; the extra size is the model and its runtime. Downloads: versions or itch.io (the -stems channels).

The STEMS SETTINGS panel under the queue has:

  • Output folder: defaults to {library}/stems, which is where Rock N Roller looks for stems. Open reveals it on disk.
  • Device (Windows and Linux): GPU or CPU. If the GPU fails, that song stops with an error; switch to CPU and press Start stem queue again. CPU is slower but always works.
  • MP3 bitrate: 128, 192 (default), 256 or 320 kbps.
  • Batch size (default 8): lower uses less GPU memory; higher is faster on bigger GPUs and M-series Pro / Max chips.

Stemming workflow

  1. Download the stems build for your platform from versions.
  2. Bind your library folder in Settings and scan it, if you have not already (settings).
  3. In LIBRARY, right-click a song and choose Add to stems queue (songs that already have stems offer Re-stem). While a song without stems is playing, the Stems button in the playback bar offers Stem song too.
  4. Open the STEMS tab and press Start stem queue. Progress shows in the queue and in the top bar, so you can go back to playing. Stop after current, Cancel all and Clear finished manage the list.
  5. Each finished song is marked as having stems straight away; no re-sync needed. For Eagles_Hotel-California_v1_1_p.psarc the worker writes: 
    {library}/stems/Eagles_Hotel-California_v1_1_p/
  drums.mp3  bass.mp3  other.mp3
  vocals.mp3  guitar.mp3  piano.mp3

How they link to PSARCs

Rock N Roller takes the PSARC filename without .psarc, looks for {library}/stems/{that_name}/, and requires all six MP3s. Only then is the song marked has_stems in SQLite. Paths are indexed per song; your PSARC and stem audio stay on disk — the database only stores metadata.

Folder name must match the PSARC basename exactly. If the chart is Foo_p.psarc, the six files have to live in Foo_p/, not Foo/ or a renamed folder. A Mac archive Foo_m.psarc writes Foo_m/ the same way, so a PC copy and a Mac copy of one song keep separate stem folders.

Mixer in Rock N Roller

When a song has all six stem MP3s indexed, the Stems popup turns stem mode on and sets per-stem levels. Each fader runs 0–2.0 (shown as 0–200%; default 1.0) so you can mute or boost parts for practice. Playback opens six streaming MP3 decoders under one mixer that shares the same time-stretch path as normal audio, so practice speed still holds pitch. Long songs stream stems with seek points instead of loading them whole.

Mixer controls: settings. Transport and loop keys: keybinds.

Find songs that have stems

Catalog search filters on the SQLite flag, not by reopening files:

  • stems="true" — songs with all six external stem MP3s indexed
  • stems="true" tuning="E Standard | Drop D" — stemmed charts in either tuning

Standalone Demucs App

Demucs App is the same separator as the stems builds, in its own window. Use it when you play Rock N Roller on the web or from a standard download. It takes MP3, WAV, OGG, FLAC, M4A, or a Rocksmith .psarc, and writes the same six-file folders.

Download the build for your machine. These are the same workers the Rock N Roller stems builds use:

The Mac apps are unsigned. If macOS blocks one, run xattr -cr on DemucsMlxCArmMacSilicon.app or DemucsOnnxMac.app, then open it again.

  1. Add files, or drop them on the window. A .psarc is fine; the app pulls the song audio out itself.
  2. Set Output folder to {library}/stems (the folder Rock N Roller already scans). If you leave it alone, files go to Documents/psarc/stems.
  3. Leave Format on MP3. Rock N Roller only picks up the six MP3s.
  4. On Windows, Device chooses GPU or CPU. If the GPU fails, that file stops; switch to CPU and press Start again. Apple Silicon always uses the GPU. Intel Mac and Linux run on the CPU.
  5. Press Start. Eagles_Hotel-California_v1_1_p.psarc becomes stems/Eagles_Hotel-California_v1_1_p/ with drums, bass, other, vocals, guitar and piano. Then Batch sync in Rock N Roller.

Try it on the web

?demo=stems loads curated demo PSARCs plus 6-stem MP3 trees into /weblib/DemoStems. That root is additive — it does not replace any stems folders you already granted. It is a larger download than ?demo=songs (charts only). Chromium required; nothing is uploaded.

Rock N Roller 0.2.7

A free guitar and bass practice app for your Rocksmith songs. Pick a song and you are playing along in under two seconds. It plays Rocksmith-format .psarc charts from your own computer: official Rocksmith 2014 DLC you own, or freeware CDLC from the CustomsForge community, PC *_p.psarc and Mac *_m.psarc on any platform. Your library stays on disk; nothing is uploaded.

Bring your own guitar tone. There is no guitar cable or microphone input, and no scoring: the app plays the song and shows the chart. Your guitar sound comes from a real amp, or an audio interface into amp software such as BIAS FX, GarageBand, Logic Pro, Guitar Rig or Neural DSP. A Rocksmith Real Tone Cable works as a USB input for those apps.

  • 3D highway or wrapping TabSheet, per part
  • Lead, Rhythm, Bass, Combo and bonus parts, plus Lyrics and Chords + Lyrics
  • Resizable layouts: one, two, three or four parts on screen; drag the line between cells to resize
  • Built-in Demucs stems in the -stems downloads for macOS, Windows and Linux
  • Pitch-preserving practice speed (0.3×–3.0×), section loops, playlists, profiles, left-handed mode

Not affiliated with Ubisoft or Rocksmith. This app does not host or distribute official DLC. It reads chart files you already have.

Web play needs Chrome or Edge. Nothing is preloaded: open Play, then point Settings at your library. ?demo=songs and ?demo=stems are optional curated downloads (stems is the larger one).

Desktop builds: macOS Apple Silicon (macOS 11+), macOS Intel (10.15 Catalina+), Windows, and Linux x86_64 — also on this itch page. Each comes in a standard build (about 4 MB) and a -stems build with Demucs built in (about 125–195 MB). Desktop reads the Steam folder directly.

The Linux build is a tar.gz. Extract it and run ./RockNRoller. It needs an X11 or Wayland desktop with OpenGL 3.3. The folder picker uses zenity or kdialog; Open folder uses xdg-open.

Library folder

Settings stores one folder: a Rocksmith 2014 install, or any folder with the same layout. Choose that folder, not dlc/ itself, then Batch sync.

MyLibrary/
  songs.psarc   # optional; audio for Rocksmith 1 import packs
  dlc/          # *_p.psarc and *_m.psarc, subfolders included
  stems/        # optional Demucs mixes, one folder per chart

If you own Rocksmith 2014, choose the Steam Rocksmith2014 folder:

  • macOS: ~/Library/Application Support/Steam/steamapps/common/Rocksmith2014
  • Windows: C:\Program Files (x86)\Steam\steamapps\common\Rocksmith2014
  • Linux: ~/.steam/steam/steamapps/common/Rocksmith2014

Official DLC already lives in dlc/. Custom charts can sit beside it or under dlc/cdlc/. Open folder (desktop) reveals that root so you can drop CDLC in.

If you do not own the game, create any folder. The app adds dlc/ and stems/ if they are missing. Put charts in dlc/ and choose the parent.

dlc/ is scanned recursively. Hidden folders are skipped. Archives sitting next to dlc/ (not inside it) are not catalogued. After you add or move charts, Batch sync again.

Web player: Chrome will not open Program Files, AppData, or ~/Library — where Steam installs the game. Copy songs.psarc, dlc/, and stems/ to an ordinary folder such as Documents/RockNRoller and choose that. The browser grant is read-only.

Inside a song

  • Space or K — pause / resume
  • J / L — seek backward / forward 10 seconds
  • , — go to the song start (or the section-loop start). Already near that start, or a quick second press, skips to the previous song
  • . — next song in the queue
  • ← / → — speed presets 0.50 → 0.80 → 1.00 → 1.25 → 1.50 → 2.00
  • [ / ] — speed ±0.1× (clamped 0.3–3.0). Click the speed number to type a value
  • P — toggle section loop (seeks to that section). Enter or O jumps back to the loop start
  • Z — zen mode: the highway fills the window
  • Esc — close a popup, cancel speed typing, or return to the catalog. Audio keeps playing. Esc does not quit

Catalog (search not focused): ↑ / ↓ move the selection, Enter plays it. In the search field, Esc clears and unfocuses.

Search

Bare words match title, artist, album, year, and tuning. Inside quotes, comma means AND and | means OR.

  • artist="Rush" instruments="l, b" — Rush charts with both lead and bass
  • tuning="Drop D" — or per part, instruments="l-E Standard" (v l r b c; +l is a bonus lead)
  • stems="true" — all six stem MP3s indexed
  • psarc="m" — Mac archives only. psarc="p|m" — either
  • other="false" — CDLC. other="true" — other / official Rocksmith DLC

Stems

Mute the chart guitar and play over the band. The -stems builds separate songs in-app: right-click a song in LIBRARY, choose Add to stems queue, then Start stem queue on the STEMS tab. Apple Silicon runs on the GPU (Metal); Windows on the GPU through DirectML (NVIDIA, AMD or Intel) or the CPU; Intel macOS and Linux on the CPU. Output goes to {library}/stems. Standard builds and the web player play existing stems; to make them there, use the standalone Demucs App (MLX on Apple Silicon, ONNX everywhere else) and Batch sync.

All six MP3s are required. The folder name is the chart filename without .psarc:

stems/Eagles_Hotel-California_v1_1_p/
  drums.mp3  bass.mp3  other.mp3
  vocals.mp3  guitar.mp3  piano.mp3

In a song, Stems sets each fader from 0–200%. Practice speed still holds pitch.
